Making History

1. Acompanhar pedido

História:
Como usuário, quero acompanhar meu pedido para saber onde ele está.

INVEST:

• I: independente
• N: pode ser ajustada
• V: ajuda o usuário
• E: fácil de estimar
• S: pequena
• T: pode ser testada

Critérios:

• Dado que fiz um pedido, quando o restaurante aceitar, então aparece “Pedido recebido”.
• Dado que o pedido está sendo preparado, quando ficar pronto, então aparece “Saiu para entrega”.
• Dado que saiu para entrega, quando for entregue, então aparece “Entregue”.

MoSCoW: Must Have

2. Item indisponível

História:
Como restaurante, quero marcar um item como indisponível para evitar pedidos desse produto.

INVEST:

• I: independente
• N: pode ser ajustada
• V: evita problemas nos pedidos
• E: fácil de estimar
• S: pequena
• T: pode ser testada

Critérios:

• Dado que o item está disponível, quando o restaurante marcar como indisponível, então ele fica indisponível.
• Dado que o item está indisponível, quando o cliente acessar o cardápio, então não poderá adicioná-lo.
• Dado que o item voltou a estar disponível, quando o restaurante alterar o status, então ele poderá ser comprado novamente.

MoSCoW: Must Have

⸻

3. Problema na entrega

História:
Como entregador, quero informar um problema durante a entrega para que ele seja resolvido.

INVEST:

• I: independente
• N: pode ser ajustada
• V: ajuda a resolver problemas
• E: fácil de estimar
• S: pequena
• T: pode ser testada

Critérios:

• Dado que estou fazendo uma entrega, quando acontecer um problema, então posso registrá-lo.
• Dado que estou registrando um problema, quando enviar a descrição, então o sistema salva a ocorrência.
• Dado que o problema foi enviado, quando for registrado, então aparece uma confirmação.

MoSCoW: Should Have

⸻
