# Atividade 4 – Elicitação de Requisitos

## 1. Registro de pedidos

Requisito 1: O sistema deve registrar novos pedidos.

Fonte 1: Entrevista com vendedor. Humana, operacional, usuário vendedor.  
Fonte 2: Processo de vendas. Humana, operacional, usuário.

Requisito 2: O sistema deve calcular o valor total do pedido.

Fonte 1: Entrevista com vendedor. Humana, operacional, usuário vendedor.  
Fonte 2: Política de preços. Não humana, documentação.

Requisito 3: O sistema deve registrar a forma de pagamento.

Fonte 1: Entrevista com vendedor. Humana, operacional, usuário vendedor.  
Fonte 2: Política de pagamento. Não humana, documentação.

---

## 2. Produtos

Requisito 4: O administrador deve cadastrar produtos.

Fonte 1: Entrevista com administrador. Humana, tático, usuário administrador.  
Fonte 2: Cadastro de produtos. Não humana, documentação.

Requisito 5: O administrador deve editar produtos cadastrados.

Fonte 1: Entrevista com administrador. Humana, tático, usuário administrador.  
Fonte 2: Sistema antigo. Não humana, sistema legado.

Requisito 6: O administrador deve remover produtos.

Fonte 1: Entrevista com administrador. Humana, tático, usuário administrador.  
Fonte 2: Catálogo de produtos. Não humana, documentação.

---

## 3. Controle de estoque

Requisito 7: O sistema deve dar baixa no estoque após uma venda.

Fonte 1: Entrevista com equipe de estoque. Humana, operacional, usuário estoque.  
Fonte 2: Sistema antigo. Não humana, sistema legado.

Requisito 8: O sistema deve registrar a entrada de produtos.

Fonte 1: Entrevista com equipe de estoque. Humana, operacional, usuário estoque.  
Fonte 2: Nota fiscal. Não humana, documentação.

Requisito 9: O sistema deve avisar quando o estoque estiver baixo.

Fonte 1: Entrevista com equipe de estoque. Humana, operacional, usuário estoque.  
Fonte 2: Regra de estoque mínimo. Não humana, documentação.
